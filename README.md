## Status taxonomy

| | Status | Meaning |
|---|---|---|
| 💀 | should-not-exist | Technically feasible, morally not |
| 🤨 | questionable | Unclear whether this is a business or a symptom |
| 🟡 | disturbingly-plausible | Would work. That is the problem. |
| 🟢 | would-pay-for-this | I personally would be a customer |
| 🚀 | accidentally-a-startup | The joke stopped being a joke |
| 🪦 | killed | Investigated further, turned out to be impossible |
| 😐 | already-exists | Happens surprisingly often |

## Batch naming

Ideas are grouped in batches, YC style:

- **W** = Winter (January to May)
- **S** = Summer (June to December)

So an idea that came to mind in August 2026 belongs to **S26**. A new batch opens when the season changes, whether or not the previous one produced anything of value. It usually does not.
